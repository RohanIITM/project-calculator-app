# Calculator App

This is a simple single-page Calculator web application built using HTML and JavaScript, styled with Bootstrap 5.

## Setup and Installation

1. **Clone the Repository**: Start by cloning the repository to your local machine using `git clone <repository-url>`.

2. **Open `index.html` in Browser**: Once cloned, navigate to the project directory and open the `index.html` file with your preferred web browser.

This app does not require any complex setup, backend services, or package installation, as it is a purely frontend application.

## Features

- Perform basic arithmetic operations: addition, subtraction, multiplication, and division.
- Responsive design with a clean and user-friendly interface.

## Technologies Used

- **HTML5** for structuring the page.
- **CSS3** for styling, leveraging **Bootstrap 5** for a responsive layout.
- **JavaScript** for dynamic calculations and updating the user interface.

## Usage

- Click on the numeric buttons to input numbers.
- Use the operation buttons ( +, -, *, / ) to choose an arithmetic operation.
- Click '=' to calculate the result of the input expression.
- Use the 'C' button to clear the input field.
